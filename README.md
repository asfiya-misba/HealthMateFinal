# HealthMate

**HealthMate** is a cross-platform fitness app built with React Native, enabling users to track their fitness goals like step counting and water intake reminders. It uses a Node.js backend with a MySQL database and Redux for state management.

## Features

- Step counter  
- Water intake reminders  
- Secure user authentication  

## Tech Stack

- **Frontend**: React Native, Redux  
- **Backend**: Node.js, MySQL  
- **Testing**: Mocha, Unit Testing
